# Shopify Email Marketing Masterplan

Implementation repository for Hair Solutions Co.'s lifecycle email system.

The operating source of truth is the **Shopify Email Marketing Masterplan** in Notion. This repository holds approved implementation assets, templates, lifecycle documentation, and reporting definitions.

## Structure

- `strategy/` — masterplan, lifecycle map, and segmentation policy.
- `automations/` — approved automation implementation and QA evidence.
- `campaigns/` — calendar exports and campaign briefs.
- `templates/` — approved HTML, Liquid, and reusable email blocks.
- `analytics/` — KPI definitions and reporting notes.
- `docs/` — platform implementation and release checks.

## Working rule

Build only from an approved Notion blueprint. Respect consent, purchase exits, suppression rules, and the customer lifecycle state in every implementation.
